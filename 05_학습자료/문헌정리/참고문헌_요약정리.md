# 참고문헌 요약 정리

PC/서버 백그라운드 보안 에이전트형 AI 논문 준비를 위한 배경 논문 9편 요약입니다. 각 항목은 (1) 서지정보, (2) 핵심 내용 요약, (3) 우리 논문과의 연결점 순으로 정리했습니다.

---

## 1. 데이터셋 원본 논문

### 1-1. VADViT: Vision transformer-driven memory forensics for malicious process detection and explainable threat attribution
**Dehfouli, Y., & Lashkari, A. H. (2025). *Journal of Information Security and Applications*, 94, 104200.**

- BCCC-MalMem-SnapLog-2025 데이터셋을 최초로 소개한 논문이다.
- 기존 메모리 포렌식 연구가 정적 바이너리나 오래된 특징 집합에 의존하던 한계를 지적하며, 실행 중인 프로세스의 메모리(VAD, Virtual Address Descriptor 영역)를 일정 간격으로 스냅샷 촬영해 시간에 따른 행위 변화를 추적하는 방식을 제안한다.
- 스냅샷은 30초 간격으로 촬영되며, 각 프로세스 ID(PID)를 지속적으로 추적하여 악성코드가 실행 중 어떻게 진화하는지 기록한다.
- 탐지 모델(VADViT)은 VAD 영역을 마르코프·엔트로피·강도(intensity) 이미지로 변환한 뒤 비전 트랜스포머로 분류하며, 이진 분류에서 약 99%, 다중 클래스 분류에서 93% 수준의 F1-score를 보고했다.
- **연결점**: 우리 연구의 주실험 데이터셋(BCCC-MalMem-SnapLog-2025)이 만들어진 배경과 원래 설계 의도(주기적 스냅샷 = 상시 모니터링 시나리오)를 이해하는 데 필수적인 논문이다. 데이터 구조 파악(Phase 1) 단계에서 반드시 재확인해야 한다.

### 1-2. Dynamic Malware Behavior Dataset (DMBD) July 2025
**Lawrence Livermore National Laboratory (LLNL), 데이터셋 공식 문서.**

- 65,416개 소프트웨어 샘플(정상/악성)의 5분간 실행 로그를 담은 대규모 행위 데이터셋이다.
- LLNL 자체 개발 도구인 Wintap을 이용해 호스트 텔레메트리(프로세스 생성/종료, 이미지 로드, 파일 생성, 네트워크 연결, 레지스트리 변경)를 수집했다.
- 라벨링은 약 80개 백신 엔진의 합의 투표(consensus voting)로 결정되어 신뢰도가 높다.
- 학습셋은 2017~2023년 악성코드로, 테스트셋에는 2024년 신종 악성코드를 별도로 포함시켜 "시간적 일반화(temporal generalization)" 문제를 의도적으로 부각시킨 벤치마크 설계가 특징이다. 베이스라인 모델은 검증 정확도 95.0%, 테스트 정확도 95.4%를 기록했지만 신종 샘플에서는 성능이 하락한다고 보고한다.
- **연결점**: 우리 연구의 교차검증 데이터셋으로, 특히 "시간적 일반화 실패"라는 문제의식은 우리 논문 8.2절(한계 및 향후 연구)의 논지와 직접 연결된다.

## 2. 배경 및 문제의식

### 2-1. ML-Based Behavioral Malware Detection Is Far From a Solved Problem
**arXiv:2405.06124 (2024)**

- 최근 ML 기반 행위 탐지기들이 벤치마크에서 매우 높은 정확도(90%대 후반)를 보고하지만, 실제로는 문제가 해결된 것과는 거리가 멀다고 비판적으로 지적하는 논문이다.
- 벤치마크 성능이 실제 운영 환경의 위협을 과대평가하게 만드는 요인들 — 데이터셋 편향, 회피 공격에 대한 미검증, 시간에 따른 개념 변화(concept drift) — 을 체계적으로 짚는다.
- **연결점**: 우리 논문 서론(1.1절)의 핵심 문제의식 — "탐지 정확도가 높아도 보안 성능이 좋다고 할 수 없다" — 과 정확히 일치하는 논문이다. 서론 인용문헌으로 적합하다.

### 2-2. Nebula: Self-Attention for Dynamic Malware Analysis
**arXiv:2310.10664 (2023)**

- 동적 악성코드 분석(실행 중 행위를 관찰하는 방식)의 배경과 대표 기법들을 정리한 논문이다.
- 공격자들이 정상 사용자 행위를 흉내 내거나 합법적 도구를 악용하는 "living-off-the-land" 방식 등 최신 공격 동향도 함께 소개한다.
- **연결점**: 2장(관련 연구)에서 동적 행위 분석 일반을 설명할 때 배경 지식으로 활용할 수 있다.

## 3. 프라이버시 유출 (멤버십 추론 공격)

### 3-1. Membership Inference Attacks against Machine Learning Models
**Shokri, R., Stronati, M., Song, C., & Shmatikov, V. (2017). *IEEE Symposium on Security and Privacy (S&P)*. / arXiv:1610.05820**

- 멤버십 추론 공격(MIA)을 최초로 체계화한 고전적 논문이다.
- 공격자가 모델에 블랙박스로 질의만 가능한 상황을 가정하고, 모델이 학습 데이터에 대해 보이는 확신도(confidence)와 평가 데이터에 대한 확신도의 분포 차이를 학습하는 별도의 "공격자 모델"을 구축해 특정 샘플의 학습 데이터 포함 여부를 추정한다.
- 상업용 ML 서비스(Google, Amazon 등)로 학습된 모델을 대상으로 실제 공격을 검증했으며, 병원 퇴원 기록처럼 민감한 데이터셋에서도 공격이 유효함을 보였다.
- **연결점**: 우리 실험의 멤버십 추론 공격 구현이 이 논문의 기본 방법론(확신도 기반 공격자 분류기)을 그대로 차용한다. 4.3절(진단 절차) 서술 시 정확히 인용해야 하는 핵심 논문이다.

### 3-2. Exposing and Defending Membership Leakage in Vulnerability Prediction Models
**arXiv:2512.08291 (2025)**

- 보안 도메인(소프트웨어 취약점 예측 모델)을 대상으로 한 멤버십 추론 공격 사례 연구다.
- 공격자가 모델의 출력 로짓(logit)을 관찰해 멤버십을 추정하는 절차를 정형화하고, 이에 대한 방어 기법도 함께 논의한다.
- **연결점**: "보안 목적으로 만들어진 AI 모델 자체가 프라이버시 위협이 될 수 있다"는 우리 논문의 위협 모델(3.1절)과 가장 유사한 도메인의 최신 사례다.

## 4. 강건성 (적대적 회피 공격)

### 4-1. Tarallo: Evading Behavioral Malware Detectors in the Problem Space
**arXiv:2506.02660 (2025)**

- 행위 기반 악성코드 탐지기를 실제 환경(feature space가 아닌 problem space, 즉 실제로 실행 가능한 악성코드 자체를 변형하는 방식)에서 회피하는 최신 기법을 다룬다.
- 특징 값을 단순히 수학적으로 조작하는 것이 아니라, 실제로 동작 가능한 악성코드가 정상 행위와 유사하게 보이도록 변형하는 현실적 제약을 고려한다는 점이 특징이다.
- **연결점**: 우리가 구현한 mimicry 탐색 기반 회피 공격(4.3절, 5.3절)과 개념적으로 가장 가까운 2025년 최신 연구로, 관련 연구(2장) 및 한계(8.2절) 논의에 인용하기 좋다.

## 5. 리소스 효율성 (경량화 및 오버헤드)

### 5-1. LIGHT-HIDS: A Lightweight and Effective Machine Learning-Based Framework for Robust Host Intrusion Detection
**Gungor, O., Kale, I., Zhou, J., & Rosing, T. (2025). arXiv:2509.13464. (UC San Diego)**

- 엣지 컴퓨팅 환경에서 호스트 침입탐지시스템(HIDS)의 추론 지연이 그 자체로 보안 위험(공격자가 악용 가능한 시간 창)이 된다는 문제의식에서 출발한다.
- 기존 최신 ML 기반 HIDS들이 높은 연산 비용의 구조에 의존해 실제 배포가 어렵다는 점을 지적하며, 정확도와 효율성을 동시에 확보하는 경량 프레임워크를 제안한다.
- **연결점**: 우리 논문 6.3절(경량화를 통한 리소스 효율화)과 문제의식·해법 모두에서 가장 직접적으로 맞닿는 논문이다. 6.3절 서술의 핵심 인용문헌으로 적합하다.

### 5-2. Evaluating Machine Learning-Driven Intrusion Detection Systems in IoT: Performance and Energy Consumption
**Jamshidi, S., Nafi, K. W., Nikanjam, A., & Khomh, F. (2025). arXiv:2504.09634. (Polytechnique Montréal)**

- ML 기반 침입탐지시스템(IDS)이 실제로 CPU 사용률·에너지 소비·CPU 부하에 어떤 영향을 미치는지 실측한 실증 연구다.
- 실시간 위협이 있는 상황과 없는 상황을 나누어 비교하고, SDN(Software-Defined Networking) 적용 여부에 따른 차이도 분산분석(ANOVA)으로 검증했다.
- **연결점**: 우리 논문의 리소스 오버헤드 진단(4.3절, 5.4절) 방법론을 설계할 때, 어떤 지표를 어떻게 측정해야 하는지 참고할 실증 연구 사례로 유용하다.
