## 2. 구현 핵심

```python
def infer(kind, m, X):
    """추론 1회 (전처리 제외)"""
    if kind in ('tree', 'mlp'):
        return m.predict_proba(X)[:, 1]
    bases, meta = m                                    # 스태킹은 베이스 4개 + 메타
    return meta.predict_proba(
        np.column_stack([b.predict_proba(X)[:, 1] for b in bases]))[:, 1]

def preprocess(kind, X):
    """전처리 비용 (MLP만 스케일링 필요)"""
    return sc.transform(X) if kind == 'mlp' else X

infer(kind, m, Xb)                                     # 워밍업

t_inf = []
for _ in range(N_REP):
    t0 = time.perf_counter(); infer(kind, m, Xb); t_inf.append(time.perf_counter() - t0)
```

## 4. 기준 배치 확정 (프로토콜 반영)

§10.1의 리소스 개선 조건("샘플당 지연 > 1ms")이 **어느 배치 기준인지 미지정**이었고, 실측 결과 모델 A가 배치에 따라 충족/미충족이 갈렸다.

```
batch=10   → 1.2209ms > 1ms   → 조건 충족
batch=1000 → 0.0441ms         → 미충족
```

**batch=10으로 고정**했다. §1A.2의 연구 맥락상 실시간 에이전트는 이벤트 발생에 따라 소량씩 분류하며, batch=1,000은 오프라인 일괄 분석에 해당하기 때문이다. 세 배치 모두 보고하되 판정은 batch=10으로만 한다.

→ **Phase 6에서 모델 A만 리소스 개선 대상**이 된다.

# 제2부. 멤버십 추론 공격 (§5)

## 5. 설계

| 항목 | 설정 |
|---|---|
| 방식 | §5.2 **옵션 B**(DMBD에 family 구조 부재) + §5.3 **1순위 shadow model** |
| Shadow 모델 | 5개. Train 24,000에서 매번 12,000을 무작위 추출해 학습 |
| Member / Non-member | Train / Validation |
| 교란 통제 | **연도 분포 매칭** — 연도별로 min(개수)만큼 양쪽에서 추출 (§5.2) |
| 역할 3분리 | 공격학습 50% / 개선안선택 25% / **최종감사 25%** (§5.1) |
| 공격자 관측 정보 | 예측 확률만 (블랙박스) |

**공격 특징 3종**: 최대 확신도, 정답 클래스 확률, 예측 분포 엔트로피

```python
def attack_features(proba, ytrue):
    conf = proba.max(1)
    p_true = proba[np.arange(len(ytrue)), ytrue]
    ent = -(proba * np.log(proba + 1e-12)).sum(1)
    return np.column_stack([conf, p_true, ent])
```

**연도 매칭 구현** — DMBD의 주요 잠재 교란 요인이 연도이므로(§11.2.1), member/non-member의 연도 분포를 강제로 일치시킨다.

```python
def match_year(idx_a, idx_b, rs):
    ya, yb = year[idx_a], year[idx_b]
    keep_a, keep_b = [], []
    for v in np.unique(np.concatenate([ya, yb])):
        aa, bb = idx_a[ya == v], idx_b[yb == v]
        n = min(len(aa), len(bb))
        if n == 0: continue
        keep_a.append(rs.choice(aa, n, replace=False))
        keep_b.append(rs.choice(bb, n, replace=False))
    return np.concatenate(keep_a), np.concatenate(keep_b)
```

매칭 후 member 7,996 / non-member 7,996 → 3분리로 **최종감사 1,999 + 1,999**

## 6. 결과 (최종 감사셋)

AUC 신뢰구간은 Hanley-McNeil 표준오차로 산출했다.

| 모델 | AUC_adv | 95% CI | 판정 | TPR@1%FPR | 확신도 격차 |
|---|---|---|---|---|---|
| **A: RF 기본** | **0.5720** | [0.5544, 0.5897] | **유출 검출** | 0.0138 | +0.0291 |
| B: RF+BO | 0.5259 | [0.5080, 0.5437] | 유출 검출 | 0.0102 | +0.0065 |
| C: 스태킹 | 0.5230 | [0.5052, 0.5409] | 유출 검출 | 0.0165 | +0.0013 |
| **D: MLP** | 0.5001 | **[0.4822, 0.5180]** | **미검출** | 0.0100 | −0.0014 |

> AUC_adv = max(AUC, 1−AUC) (§5.4 방향 보정 지표). 전 모델에서 원시 AUC가 0.5 이상이어서 보정 전후가 동일했다.

### 6.1 Phase 3 과적합 진단과의 일치

| 모델 | Train−Val MCC 격차 | MIA AUC_adv |
|---|---|---|
| A | 0.1530 | 0.5720 |
| B | 0.0713 | 0.5259 |
| D | 0.0080 | 0.5001 |

**과적합 격차 순서가 MIA 취약성 순서와 정확히 일치**한다. 중간 분석(2026-09-19)에서 이 순서를 사전 예측했으며 결과가 부합했다.

### 6.2 D의 미검출 서술 (§5.3 필수 문구)

> 사전 정의된 공격 조건 및 공격 강도 하에서 멤버십 신호가 검출되지 않았다. **이는 프라이버시가 보장됨을 의미하지 않는다.**

### 6.3 TPR@low-FPR 관점

전 모델의 TPR@1%FPR이 0.0100~0.0165로, 무작위 기준(0.01) 대비 최대 1.65배에 그친다. Carlini et al.(2022)의 기준 — **평균 AUC가 아니라 낮은 FPR에서의 TPR로 평가해야 한다** — 을 적용하면, 검출된 유출은 **실용적 위협 수준에 이르지 못한다.** AUC만 보고하면 위험을 과대평가하게 된다.

## 10. H2 — 중요도와 민감도의 상관

민감도 `S_i`는 §6.4의 부호 정의에 따라 **확률 감소폭의 기울기**로 산출했다(클수록 민감).

```python
xs = np.array([r['step'] for r in rows])
ys = np.array([r['mean_prob_drop'] for r in rows])
S = float(np.polyfit(xs, ys, 1)[0])       # S_i = -Δp/Δreduction
```

## 11. 발견 — "중요도"와 "비례 감소 민감도"는 다른 속성이다

`net_connect`는 A·B·C에서 순열 중요도 **1~2위**임에도 30% 감소 교란에서 **flip rate 0.0000**이었다.

| 모델 | `net_connect` 중요도 | 순위 | 30% 감소 flip rate |
|---|---|---|---|
| A | +0.1976 | 2위 | 0.0000 |
| B | +0.1603 | 1위 | 0.0000 |
| C | +0.1929 | 1위 | 0.0000 |

**원인**: 두 측정이 가하는 조작이 다르다.

- **순열 중요도**: 값을 표본 간 **무작위로 뒤섞는다** → 악성 샘플에 정상 수준의 값이 들어가 경계를 넘는다
- **본 연구의 교란**: 값을 **일정 비율로 감소**시킨다 → 네트워크 연결이 많은 악성 샘플을 30% 줄여도 여전히 정상 분포보다 높아 경계를 넘지 못한다

**보고 방침**: 프로토콜을 사후 수정하지 않는다. 본 관측을 §13.1에 기록하고 논의에 포함하며, 향후 연구에서 교란 방식을 "정상 분포로의 이동(mimicry)"으로 확장할 것을 제안한다.

**실무적 함의**: 공격자가 네트워크 활동량을 30% 줄이는 정도의 조작으로는 본 탐지기를 회피할 수 없다.

## 12. H1 판정

프로토콜 §1.1 기준 — *"한 모델이라도 탐지 성능은 상위인데 다른 축에서 하위인 사례가 관측되면 H1 지지"*

**형식적으로는 반례가 성립한다**: 탐지 1위인 **B가 프라이버시에서는 3위**이며, 탐지가 더 낮은 C가 프라이버시에서 더 안전하다.

**단, 크기를 정직하게 명시해야 한다**: B와 C의 AUC_adv 차이는 **0.0029**이며 두 CI가 크게 겹친다([0.5080, 0.5437] vs [0.5052, 0.5409]). 순위상 반례이나 실질적 크기는 미미하다.

**더 설득력 있는 관찰은 D다**: 탐지가 압도적으로 낮은 대신(−0.2075) 프라이버시와 지연 모두 1위다. 이는 명백한 트레이드오프이며 효과 크기도 크다. 다만 이는 **"높은 탐지 ≠ 안전"이 아니라 "낮은 탐지 = 다른 축 우수"**로, H1이 말하는 방향과는 다르다.

> H1은 확증적 가설이 아니므로(§1.1) 유의성 검정을 수행하지 않으며, 위 순위표를 병렬 제시하고 관찰을 서술하는 것으로 갈음한다.
